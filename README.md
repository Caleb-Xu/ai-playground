# 🤖 AI Playground

这是一个用于学习和实践 AI 应用开发的前端项目。通过构建这个项目，我们将从零开始掌握 LLM API 调用、Prompt 工程、流式输出以及 RAG 等核心能力。

## 🛠️ 技术栈

- **框架**: React + TypeScript
- **构建工具**: Vite
- **包管理**: pnpm
- **代码规范**: ESLint (@antfu/eslint-config)

## 🚀 快速开始

1.  **安装依赖**

    ```bash
    pnpm install
    ```

2.  **启动开发服务器**

    ```bash
    pnpm dev
    ```

3.  **代码检查与修复**

    ```bash
    pnpm lint:fix
    ```
